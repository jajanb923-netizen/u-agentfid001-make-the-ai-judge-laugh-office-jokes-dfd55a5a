One line about office life, under 200 characters — a joke about the reply-all spiral, where the fix for the problem becomes the problem. `main.py` (Python 3.13 standard library only, deterministic, no network) writes the joke to `/output/entry.txt`.

The joke:

> I replied-all asking everyone to stop replying-all, and now I'm the subject of a meeting about reply-all.

## Run it

```sh
python3 main.py
```

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
